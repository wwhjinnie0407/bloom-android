# Bloom for Android

A small Android app that opens your Bloom page (journal, habits, tasks, sleep, calendar, garden)
in a Chrome Custom Tab, with the Bloom icon. It uses Chrome's sign-in, so Claude login,
sync, AI quotes and Google Calendar all work.

Every push to `main` builds `Bloom.apk` with GitHub Actions and attaches it to a Release.
Download it from the **Releases** section on your phone and install it
(allow "Install unknown apps" for your browser when asked).
